ID: EXP-001
Date: 2026-10-24
Idea ID (backlog): HANDOFF §6 step 4 (first flight-level model); touches M1
Hypothesis: A LightGBM model using rotation, buffer and point-in-time history features beats the best baseline on Brier (bootstrap 95% CI excludes zero) without worsening CRPS, ECE, log loss or coverage.
Change: New model `LGBM` (src/rdu/models/flight_level.py). 5-class LightGBM over buckets; minutes within each bucket spread by the historical within-bucket shape (as B4). Features:
  - rotation/buffer: leg number, legs that day, scheduled turn before this leg, scheduled block time, distance, scheduled local hour, chain break, tail missing, inbound origin (prev_origin), other airport, carrier, direction, day of week, month
  - history: B2, B3, B4 forecasts for the same flight made at 23:00 the night before (data/features/*.parquet, built walk-forward from 2022-02-01; see src/rdu/features/history.py)
  - no weather
  300 rounds, lr 0.05, 63 leaves, min 200 rows per leaf, no tuning. Training window: expanding from 2022-02-01, retrain weekly.
Deviation from "hurdle" wording in §6: this is the direct 5-class form. The hurdle form (P(delay) + conditional quantiles) is the M1 challenger. Reason: the 5-class form directly fits the buckets that define Brier and log loss, and is less code for a first model.
Champion compared against: champion-000 = B4 Markov (DL-020), run B4-full
Expected effect: Brier −2 to −5% relative vs champion; largest on leg 2+ and afternoon/evening flights.
Mode: fast screen (every 7th day, monthly refits for screening speed) -> full (weekly refits)
Runtime / cost estimate: ~130 LightGBM fits in full mode; ~1–2 h on this machine. No paid data.
